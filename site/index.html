Field Notes Why slow software feels faster

Made for reading

Everything a feed reader should be. Nothing it shouldn’t.

Reads like a book

Full articles load by themselves, in a calm, uncluttered layout with sans or serif type. No mode to switch, no button to press.

Local by default

Feeds, read state and settings live on your device. No account, no telemetry, no third-party backend.

No scary permissions

The extension asks for no site access when you install it. It reaches only the sites you add, one at a time.

Finds the feed for you

On any site, open Perch: it reads the feed links the page names, or tries the usual places. RSS, Atom and JSON Feed all work.

Yours to shape

Light and dark themes, your own accent and button colours, frosted glass and a background picture of your choice.

Open source, self-hostable

MIT licensed. Run your own Perch Server with a single script — or don’t run one at all.

Sync chains

Sync without an account.

Start a chain on one device and scan its QR code on the next. Everything is encrypted on your devices with a key only they hold; the relay in between passes it on without being able to read it.

  1. 1

    Start a chain

    On any device: Settings → Sync → Start a chain.

  2. 2

    Scan or type the code

    Point your iPhone’s camera at the QR code, or enter the 28-character code in another browser.

  3. 3

    Read anywhere

    Subscriptions, read and starred articles, theme and colours follow you.

Prefer an account? Sign in to a Perch Server — ours at app.perch.ws, or one you run yourself — and read on the web too.

Privacy you can check

Built to know as little as possible.

Read the code
  • No analytics, no ads, no trackers — this page included.
  • Your password never leaves your device: Perch derives a key from it with Argon2id and sends only that.
  • Sync chains are end-to-end encrypted; even feed addresses are hidden from the relay.
  • No favicons are fetched — they would tell each site what you follow.
  • Articles render with scripts switched off.
  • perch.ws is served by Cloudflare Pages, which handles each visit like any web host. The app (app.perch.ws) and the sync relay (sync.perch.ws) don’t go through Cloudflare: your devices talk straight to our server, which keeps no access logs.
